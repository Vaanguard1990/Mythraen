# Mythraen: Fractured Souls

Mythraen: Fractured Souls is a third-person action RPG built in Unreal Engine 5.

## Vision

Explore the mist-covered region of Brumavia, forge relationships with its inhabitants, and uncover the origin of the fractured souls that threaten the land.

## Build 0.1 goals

- Explore a first playable area: Brumavia
- Move with a third-person character and camera
- Interact with NPCs and world objects
- Collect items and persist progress through save games

## Project status

The repository bootstrap and technical foundation are in progress. See [Docs/Roadmap.md](Docs/Roadmap.md) for the delivery plan.

## Getting started

1. Install Unreal Engine 5.4 or a compatible later UE5 release.
2. Open `Mythraen.uproject` once it is added to the repository.
3. Generate IDE project files and build the `MythraenEditor` target.
